# Screenshots

Evidence attached to manual test execution. Every screenshot here is referenced by a test ID or a defect ID from the case study it belongs to.

## Naming convention

`<case-study>-<ID>-<short-description>.png`

Examples:

- `ecl-DEF-001-identical-tab-titles.png`
- `ecl-TC-A11Y-002-heading-order.png`

## What belongs here

- The failing state named in a defect's actual result
- Before and after evidence when a defect is retested
- Any measurement a reader would otherwise have to take on trust

## What does not belong here

- Screenshots containing client or customer data that has not been cleared for publication
- Credentials, tokens, or infrastructure hostnames visible in the address bar or a dev tools panel

Redact before committing. A portfolio repository is public.

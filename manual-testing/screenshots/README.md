# AVIIHAI Automated Evidence Screenshots

These are not manual test screenshots. They are generated by
`automation-tests/tests/evidence.spec.js` against the live AVIIHAI application
and refreshed by GitHub Actions on every push to `main`.

Each image maps to an `EV` record in the
[AVIIHAI coverage matrix](../../automation-tests/docs/aviihai-coverage-matrix.md).
The ECL manual cycle, test cases, defects, and report previews are in the
[ECL case-study folder](../case-studies/ecl-operations-hub/).

## Naming convention

`aviihai-<evidence-ID>-<short-description>.png`

Examples:

- `aviihai-EV-001-login-default.png`
- `aviihai-EV-012-payments-add-mobile.png`

## What belongs here

- Stable application states produced by the evidence spec
- Desktop and mobile viewport captures
- Form validation, rejected credentials, authenticated modules, and empty states

## What does not belong here

- Manual ECL report previews, which belong in the ECL case-study folder
- Screenshots containing client or customer data that has not been cleared for publication
- Credentials, tokens, or infrastructure hostnames visible in the address bar or a dev tools panel

The authenticated demo account uses non-sensitive portfolio data. Any future
evidence should still be checked before it is committed because this repository
is public.
